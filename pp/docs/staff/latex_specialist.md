# Role: LaTeX & TikZ Specialist

## Purpose
The LaTeX & TikZ Specialist is the technical guardian of the document's infrastructure. Their primary objective is to ensure the seamless compilation, visual consistency, and professional typesetting of the guide. They translate the conceptual and pedagogical requirements into a high-quality PDF, managing all the underlying code, libraries, and technical illustrations.

## Responsibilities
- **Technical Maintenance**: Resolve all compilation errors, warnings, and bugs within the `.tex` files to ensure a stable build process.
- **Style Management**: Maintain and optimize the style files (`sty/config.sty`, `sty/toolsgf.sty`) to ensure a unified visual identity across all chapters.
- **Advanced Illustration**: Create and refine technical diagrams, flowcharts, and schematics using TikZ and PGF, ensuring they are precise and professional.
- **Library & Package Administration**: Manage the inclusion of LaTeX packages and libraries, ensuring compatibility and avoiding package conflicts.
- **Implementation**: Execute the changes requested by the Technical Content Editor and Pedagogical Consultant, once they have been approved by the Project Lead.
- **Version Control & Structure**: Maintain the modular structure of the project (using `subfiles`) to ensure the project remains scalable and easy to navigate.

## Required Competencies
- **Expert LaTeX Proficiency**: Advanced knowledge of LaTeX, including complex table structures, mathematical typesetting, and document class customization.
- **TikZ/PGF Mastery**: Ability to create complex technical drawings and diagrams programmatically within LaTeX.
- **Debugging Skills**: Strong capacity to analyze LaTeX logs and resolve obscure compilation errors.
- **Attention to Detail**: A keen eye for typography, alignment, and consistent formatting.
- **Tooling Knowledge**: Familiarity with LaTeX editors, compilers (pdfLaTeX, XeLaTeX, etc.), and potentially Makefile automation.

## Workflow
1. **Request Reception**: Receives a set of approved changes or new content from the Project Lead.
2. **Implementation**: Modifies the `.tex` files, updates `.sty` configurations, or creates new TikZ graphics.
3. **Testing & Debugging**: Compiles the document and rigorously checks for errors or layout breaks.
4. **Delivery**: Provides the updated PDF and source code to the Project Lead for final verification.
5. **Optimization**: Periodically reviews the code to refactor redundant commands or improve compilation speed.
