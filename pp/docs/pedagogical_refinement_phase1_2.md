# Pedagogical Refinement: Phase 1 & 2

**Author**: Pedagogical Consultant
**Input**: Technical Proposal (Phase 1 & 2)
**Status**: Final Proposal for Project Lead Approval

## 1. Transformation of the "Fixed Costs" Chapter

### A. Theoretical Integration
The technical definition of the **Break-even Point** is correct. To avoid a purely theoretical delivery, I propose integrating it as a "Decision Tool" rather than just a formula. 

**Pedagogical Change**: Instead of a static text, we will present the formula followed by a **"Quick-Check Example"** (e.g., calculating the break-even point for a small CNC service) to provide immediate context.

### B. Activity Redesign: From Questionnaire to Workshop
I propose replacing the 11-question investigation list with a **"Cost Analysis Workshop: The Electromechanical Startup"**. 

**The New Activity Structure:**
1. **Scenario**: The student is given a list of assets (a lathe, a drill press, a small workshop rental, and a part-time accountant).
2. **Task 1 (Categorization)**: Classify each item as a *Committed* or *Discretionary* Fixed Cost.
3. **Task 2 (Calculation)**: Using the provided unit price and variable cost, calculate the **Break-even Point** for the service.
4. **Task 3 (Critical Thinking)**: "If the rental cost increases by 20%, how does this affect the break-even point?"

**Benefit**: This shifts the student from passive memorization to active professional application.

## 2. Transformation of the "Project Planning" Chapter

### A. Scaffolding the PERT Process
The technical guide for Forward/Backward passes is accurate but dense. To prevent cognitive overload, I propose a **"Guided Discovery"** approach.

**Implementation Strategy:**
- **The "Cheat Sheet"**: Create a small, highlighted box (using the `\info` or a new `\solvedexample` command) that summarizes the rules: $\text{Forward} \rightarrow \text{Max}$, $\text{Backward} \rightarrow \text{Min}$.
- **The Guided Example**: Instead of just a solved example, we will provide a **"Fill-in-the-Blanks"** example. The network is drawn, and the student must fill in the ES, EF, LS, and LF values for only 3 nodes, with the rest already completed. This builds confidence before they tackle the complex cases.

### B. Time-Boxing and Activity Management
To ensure the 160-minute weekly limit is respected, I propose the following distribution for the activities:

- **Essential (In-Class - 100 min)**:
  - Exercise 1 & 2 (Conceptual basics).
  - The Guided PERT Example.
  - Exercise 3 (The Industrial Project - core calculation).
- **Extension (Homework/Fast-Learners - 60 min)**:
  - Case: Clima Cuyo S.R.L.
  - Case: Industrias SKIP.

**Benefit**: This ensures all students achieve the minimum competence without falling behind, while providing a challenge for advanced students.
