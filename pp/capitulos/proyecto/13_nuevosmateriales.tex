\chapter{Aplicación de Nuevos Materiales al Proyecto}
\actividad{Actividad para el proyecto}
\begin{enumerate}
  \item ¿Cuál es el objetivo principal de nuestro proyecto
    relacionado con nuevos materiales?
  \item ¿Qué tipo de nuevo material estamos investigando o desarrollando?
  \item ¿Cuáles son las propiedades clave que estamos tratando de
    mejorar o aprovechar en este material?
  \item ¿Cuáles son las posibles aplicaciones prácticas de este nuevo
    material en la industria o la tecnología?
  \item ¿Cuáles son los métodos que utilizaremos para analizar y
    caracterizar las propiedades de este material?
  \item ¿Qué desafíos anticipamos en el proceso de investigación o
    desarrollo de este material?
  \item ¿Cómo evaluaremos la viabilidad económica de la producción a
    gran escala de este nuevo material?
  \item ¿Qué medidas tomaremos para garantizar la seguridad y la
    sostenibilidad en la fabricación y uso de este material?
  \item ¿Qué recursos y colaboraciones necesitamos para llevar a cabo
    con éxito este proyecto?
  \item ¿Cuáles son los plazos y hitos clave que debemos seguir para
    cumplir con los objetivos del proyecto?
\end{enumerate}
