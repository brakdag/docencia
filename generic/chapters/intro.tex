\chapter*{Introducción}
Esta guía está destinada a estudiantes de nivel secundario (13-18 años) que se inician en el mundo del Dibujo Técnico Asistido por Computadora (CAD).

El objetivo es proporcionar herramientas conceptuales para la comprensión de las normas, la lógica de representación de objetos y el uso eficiente de software CAD para la resolución de problemas técnicos, aplicables a situaciones cotidianas y profesionales.

Esperamos que el recorrido por los capítulos, desde la introducción básica hasta el desarrollo de elementos de máquina, permita adquirir competencias fundamentales para la formación técnica.
